# Leyline Tycoon (built artifacts)

Built web app for [Leyline Tycoon](https://quidam2k.github.io/leyline-tycoon-app/), a location-based magical tycoon game — tap real-world POIs to place extractors, place your Nexus, and route caravans to haul colored mana home.

This repo holds **build output only**, published via `gh-pages`. The source lives in a private repository.
