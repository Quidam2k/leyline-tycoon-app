# Leyline Tycoon (built artifacts)

Built web app for [Leyline Tycoon](https://quidam2k.github.io/leyline-tycoon-app/), a location-based magical tycoon game — tap real-world POIs to place extractors, route caravans to haul colored mana to your Nexus, and sell it for Essence to build your mana empire.

This repo holds **build output only**, published via `gh-pages`. The source lives in a private repository.
